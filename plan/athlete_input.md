# As tuas notas para o coach automático

Escreve aqui, em qualquer altura, qualquer coisa que o robô deva saber antes
de ajustar a próxima semana — dores, viagens, cansaço, boa forma, o que
quiseres. Frases simples chegam. Podes editar este ficheiro diretamente no
GitHub (ícone do lápis, no canto superior direito da página do ficheiro).

Uma nota antiga não faz mal ficar aqui — o robô só dá peso ao que escreveste
recentemente (a data ajuda-o a perceber isso). Podes apagar notas antigas
quando quiseres, mas não é obrigatório.

Exemplos do que podes escrever:

- 2026-09-10: Vou viajar a semana toda, sem acesso a bike.
- 2026-09-20: Joelho direito a incomodar depois de correr, com cuidado esta semana.
- 2026-10-02: Sinto-me com muita energia, podes carregar um pouco na mão.
- 2026-10-05: Dormi mal a semana toda, bastante cansado.
